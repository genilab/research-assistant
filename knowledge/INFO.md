# Knowledge-worker Knowledge Info

This is the entry point for durable, topic-based knowledge. No topics have
been migrated or created yet.

## Knowledge topics

When topics exist, list each as:

```md
- [Topic display name](topic-slug/)
```

Each topic folder is authoritative and contains:

- `references/` for preserved source material;
- `{topic-slug}_info.md` for attributed learning;
- `{topic-slug}_ideas.md` for proposals, hypotheses, and open questions;
- `{topic-slug}_refs.md` for source and relevance records.

Only `topic-create` or a verified reconciliation through
`knowledge-base-maintain` updates this info.
