# Skill Plan — paper-learn

## Summary

Learn one supplied academic paper into a confirmed research topic.

## Description

The skill gives the researcher one simple paper-intake action while retaining
the source-control and duplicate safeguards of the supporting ingestion process.

## Script Requirements

- Require an existing topic and identified paper source.
- Confirm a stable paper identifier and detect duplicates.
- Preserve an approved source unchanged or retain a durable source link.
- Update paper and topic indexes without analyzing or classifying the paper.

## Delegation to Code

No code is required; source identity and relevance require research judgment.
