# Skill Plan — info-learn

## Summary

Absorb supplied information, ideas, and source material into one existing
knowledge topic while retaining provenance and distinction between facts and
exploration.

## Description

This skill is the bounded intake workflow for an established topic. It records
the user-provided evidence, a concise synthesis, and exploratory ideas in their
separate durable records rather than flattening them into one note.

## Script Requirements

- It must identify an existing topic before changing its records.
- It must preserve each supplied source file under the topic's `references/`
  folder and record its provenance in the refs record.
- It must append source-grounded synthesis to the info record under an
  appropriate content section.
- It must append ideas, hypotheses, and open questions only to the ideas
  record.
- It must retain uncertainty, attribution, and conflicting claims rather than
  silently resolving them.
- It must refresh the topic-level INFO summary and links after durable learning.
- It must ask for clarification when the topic, source identity, or content
  classification is ambiguous.

## Delegation to Code

No code portion is currently required. Determining whether material is a fact,
an interpretation, or an idea requires contextual judgment and attribution.
