# Paper Classification Schema

Classify each paper against the topic's stated question and criteria. The
default fields below are a transparent starting point, not claims about the
paper; omit or mark a field unknown when the paper does not support it.

| Field | Record |
| --- | --- |
| Topic relevance | Direct relation to the topic question and intended use. |
| Contribution type | Theory, method, system, dataset, empirical finding, survey, position, or another named type. |
| Research problem | The concrete problem or gap the paper addresses. |
| Conceptual domains | Relevant research traditions and the paper feature supporting each mapping. |
| Evidence basis | Conceptual argument, proof, experiment, case study, survey, dataset analysis, or another stated basis. |
| Method and artifacts | Method, data, system, instrument, or protocol when available. |
| Findings and limits | Reported findings, scope conditions, threats, and unanswered questions. |
| Re-use | The question, argument, method, or comparison for which the paper may be useful. |

Keep the classification at `papers/{paper-id}/classification.md`. Topic-specific
criteria may extend this table only after the researcher provides or approves
them. Never use a category label as a substitute for evidence.
