# Skill Plan — paper-classify

## Summary

Classify one analyzed paper against stated topic criteria.

## Description

The skill applies a visible field-based schema so a classification can be
revisited and extended without treating categories as evidence.

## Script Requirements

- Require an analyzed paper and explicit default or topic-specific criteria.
- Record evidence, inference, or unknown status for every classification field.
- Preserve the analysis and update only the classification and indexes.

## Delegation to Code

No code is required; classification depends on source interpretation.
