# Skill Plan — topic-show

## Summary

Present one topic's maintained INFO index without changing it.

## Description

The skill provides the direct read-only navigation action for a researcher's
current topic state.

## Script Requirements

- Require one existing, unambiguous topic.
- Locate and present only its maintained INFO index.
- Report missing, incomplete, or ambiguous indexes without repairing them.

## Delegation to Code

No code is required; this is a read-only information presentation workflow.
