# Skill Plan — topic-brainstorm

## Summary

Explore bounded research ideas, questions, and directions for one existing topic.

## Description

The skill records persistent topic exploration in the ideas record while
preserving the distinction between attributed knowledge, hypothesis, argument,
and direction.

## Script Requirements

- Require an existing topic and a bounded brainstorming focus.
- Read accumulated topic records before generating new exploration.
- Classify durable outcomes as ideas, arguments, directions, or open questions.
- Avoid unsupported novelty, feasibility, or evidence claims.

## Delegation to Code

No code is required; topic selection requires research judgment.
