# Skill Plan — report-experiment

## Summary

Write one linked report of a planned experiment and its catalogued results.

## Description

The skill produces a scholarly empirical report while preserving the boundary
between measured observations, interpretation, limitations, and implications.

## Script Requirements

- Require a plan and catalogued results for an identified experiment.
- Use the shared experiment and academic-writing guidelines.
- Link claims to results and state deviations and validity limits.
- Index the report in both experiment and publication records.

## Delegation to Code

No code is required; reporting supplied evidence requires research judgment.
