# Skill Plan — finding-analyze

## Summary

Interpret one catalogued experimental finding set against its experiment plan.

## Description

The skill makes result interpretation traceable by comparing observed outcomes
with the measures, design, limits, and research claim that give them meaning.

## Script Requirements

- Require a plan, result catalog, and target claim or question.
- Separate observations, inference, alternatives, and open questions.
- Record deviations and validity limits.
- Update indexes without modifying raw evidence.

## Delegation to Code

No code is required; interpretation uses catalogued evidence only.
