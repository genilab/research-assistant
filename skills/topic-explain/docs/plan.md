# Skill Plan — topic-explain

## Summary

Explain one research topic from its maintained topic-level INFO index.

## Description

The skill gives a concise, evidence-bounded orientation without changing topic
records or treating unindexed material as part of the current topic state.

## Script Requirements

- Require one existing, unambiguous topic.
- Read the topic INFO as the primary source of current state.
- Explain summary, focus, linked records, directions, and open decisions.
- Report a missing or stale index rather than inferring missing content.

## Delegation to Code

No code is required; explanation is a read-only synthesis of maintained records.
