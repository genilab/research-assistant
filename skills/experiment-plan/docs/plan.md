# Skill Plan — experiment-plan

## Summary

Design one evidence-aware experiment before execution.

## Description

The skill creates a traceable plan from a research question to a decision rule
and makes measurement, validity, and operational dependencies explicit.

## Script Requirements

- Require a research question, testable claim, and available constraints.
- Specify comparison, measures, procedure, analysis, and decision conditions.
- Record validity, ethical, and operational limits.
- Create and index a topic-local plan without reporting results.

## Delegation to Code

No code is required; experimental design requires researcher judgment.
