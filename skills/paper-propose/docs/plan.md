# Skill Plan — paper-propose

## Summary

Propose one typed academic-paper structure from durable topic evidence.

## Description

The skill returns the required sections and what each must contain before any
paper drafting begins, preserving evidence gaps and open decisions.

## Script Requirements

- Require a topic, one supported paper type, audience, central question, and evidence scope.
- Return every section's purpose, content, evidence need, linkage, and gap.
- Support Vision, Survey, Experimentation, Results, and Positioning paper types.
- Create an indexed proposal without drafting the paper.

## Delegation to Code

No code is required; paper architecture requires scholarly judgment.
