# Skill Plan — literature-search

## Summary

Find related academic work using a bounded, traceable search brief.

## Description

The skill records sources, queries, dates, selection logic, and limitations so
later literature work can distinguish discovery from established evidence.

## Script Requirements

- Require a topic, question, source scope, and intended depth.
- Record search terms, sources, dates, and inclusion or exclusion decisions.
- Present candidate papers before ingestion.
- Avoid unsupported completeness and quality claims.

## Delegation to Code

No code is required; source selection requires research judgment.
