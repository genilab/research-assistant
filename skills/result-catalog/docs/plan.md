# Skill Plan — result-catalog

## Summary

Record one experiment result set with reproducible provenance.

## Description

The skill separates observed result material from its interpretation and links
it to the plan that gives its measures and decision rule meaning.

## Script Requirements

- Require an experiment identifier, result provenance, and conditions.
- Record measures, transformations, analysis, observations, and limits.
- Update experiment and topic indexes without changing source data.

## Delegation to Code

No code is required; the operation catalogs supplied outcomes.
