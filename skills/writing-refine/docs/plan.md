# Skill Plan — writing-refine

## Summary

Learn one bounded scholarly-writing convention from supplied examples.

## Description

The skill turns researcher-approved patterns into reusable guidance while
preserving example provenance and avoiding imitation or unsupported generality.

## Script Requirements

- Require supplied examples or instructions and a stated writing context.
- Derive a scoped pattern, limits, and examples of appropriate use.
- Obtain confirmation before changing shared writing guidance.
- Do not copy source prose or rewrite a target paper.

## Delegation to Code

No code is required; rhetorical interpretation requires research judgment.
