# Skill Plan — synthesis-create

## Summary

Synthesize an explicit topic paper corpus into a survey and comparison record.

## Description

The skill makes source selection, comparison dimensions, synthesis, and gaps
visible before a literature survey becomes a paper.

## Script Requirements

- Require a topic, research question, corpus, and comparison dimensions.
- Use paper analyses and classifications as traceable evidence.
- Produce a comparison table and an evidence-limited gap analysis.
- Link the resulting synthesis from topic indexes.

## Delegation to Code

No code is required; source comparison requires research judgment.
