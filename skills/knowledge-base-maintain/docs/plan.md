# Skill Plan — knowledge-base-maintain

## Summary

Reconcile the Knowledge-worker topic core and the compact Research-assistant
topic indexes from verified filesystem evidence.

## Description

This skill verifies that every topic retains the inherited information, ideas,
references, and source-material schema, then checks the research extension's
topic INFO and paper, experiment, and publication indexes.

## Script Requirements

- Inspect only verified topic folders and maintained navigation records.
- Verify the Knowledge-worker topic core plus the compact research extension.
- Refresh the main knowledge INFO solely from confirmed topic folders.
- Report missing or conflicting records without inventing topic content.

## Delegation to Code

No code is required; topic identity and record reconciliation need contextual
judgment.
