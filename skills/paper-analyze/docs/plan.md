# Skill Plan — paper-analyze

## Summary

Analyze one ingested academic paper into reusable topic-local records.

## Description

The workflow reuses the FAU method of extracting thesis, claims, reasoning,
conceptual framing, theoretical position, and a complete reference catalog.

## Script Requirements

- Read the identified source and shared analysis and writing guidelines.
- Keep extraction, analysis, and peer-review judgment distinct.
- Create separate analysis and complete-reference records.
- Record claims, evidence basis, limits, and conceptual positioning.

## Delegation to Code

No code is required; source interpretation requires research judgment.
