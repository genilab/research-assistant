# Skill Plan — argument-develop

## Summary

Develop one evidence-aware research argument or question.

## Description

The skill turns an exploratory direction into a traceable claim map without
conflating evidence, inference, and proposal.

## Script Requirements

- Require a topic, bounded focus, and available evidence or explicit gap.
- Record claim, premises, evidence links, alternatives, and dependencies.
- Update argument, direction, and topic-index records.
- Route structure or experimental needs to their dedicated skills.

## Delegation to Code

No code is required; argument assessment requires research judgment.
