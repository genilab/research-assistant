# Skill Plan — info-show

## Summary

Present the project root or one confirmed local INFO document without changing
the workspace.

## Description

This skill provides read-only internal navigation. It resolves a requested area
to its maintained INFO document and reports ambiguity or absence without
substituting a README or another record.

## Script Requirements

- Accept the root request or one named local area.
- Resolve only a confirmed local INFO document.
- Present its current contents without modifying the workspace.
- Report an absent or ambiguous target rather than guessing.

## Delegation to Code

No code is required; target resolution depends on current project navigation.
