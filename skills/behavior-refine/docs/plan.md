# Skill Plan — behavior-refine

## Summary

Learn one bounded research behavior from researcher-supplied evidence.

## Description

The skill makes behavior learning explicit, evidence-aware, and reversible by
capturing scope, activation, limits, and the smallest appropriate framework change.

## Script Requirements

- Require examples or instructions and an intended research use.
- Distinguish observation, preference, reusable behavior, and limitation.
- Obtain confirmation before a durable guideline or skill change.
- Route new skills through the managed skill-creation workflow.

## Delegation to Code

No code is required; behavioral interpretation requires research judgment.
