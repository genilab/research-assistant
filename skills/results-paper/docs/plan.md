# Skill Plan — results-paper

## Summary

Write one evidence-bounded results paper from topic experiment records.

## Description

The skill applies the shared writing and experimentation conventions to an
empirical paper while linking each claim to a catalogued observed result.

## Script Requirements

- Require identified experiment plans and result catalogs.
- Structure the paper around contribution, method, results, and validity limits.
- Preserve null, conflicting, and limited findings.
- Create and index only the requested topic-local draft.

## Delegation to Code

No code is required; scholarly synthesis requires research judgment.
